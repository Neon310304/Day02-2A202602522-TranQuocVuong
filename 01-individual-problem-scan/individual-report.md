#### Problem Card #1 — Debug code Python/AI

```text
Problem 1 câu: Sinh viên mất 30-90 phút mỗi lần debug vì phải tự xác định lỗi nằm ở dữ liệu, môi trường hay logic trong code Python/AI.

Actor: Tôi, sinh viên viết và chạy bài Python/AI; đôi khi bạn cùng nhóm hỗ trợ.

Thời điểm / bối cảnh: Khi chạy notebook/script cho assignment, khoảng 2-3 lần/tuần, thường gần deadline.

Current workflow 3-7 bước:
1. Chạy notebook hoặc script và ghi nhận lỗi/output bất thường.
2. Đọc traceback, kiểm tra dòng code và thử đoán nguyên nhân.
3. Kiểm tra dữ liệu đầu vào, package và phiên bản môi trường.
4. Sửa một giả thuyết rồi chạy lại toàn bộ hoặc một phần code.
5. Nhờ bạn hoặc tìm thêm tài liệu nếu vẫn chưa xác định được nguyên nhân.

Bottleneck: Phân loại nguyên nhân và khoanh vùng lỗi; mất khoảng 15-30 phút trước khi có một giả thuyết có thể kiểm chứng.

Impact: Mỗi lỗi mất 30-90 phút; với 2-3 lần/tuần có thể mất 1-4 giờ, làm chậm phần viết báo cáo và tiến độ nhóm.

Success metric: Giảm thời gian debug trung bình ít nhất 30%, từ tối đa 90 phút xuống dưới 60 phút/lỗi; người học vẫn hiểu và tự xác nhận được nguyên nhân.

Non-AI alternative: Dùng checklist debug cố định, log đầy đủ, test từng hàm nhỏ và ghim phiên bản package trong requirements.

AI hypothesis: Đưa traceback, đoạn code liên quan, input mẫu và môi trường cho AI để phân loại nguyên nhân, đề xuất tối đa 3 kiểm tra tiếp theo và giải thích vì sao; tôi tự chạy kiểm tra và quyết định sửa.

Quick gut:
[ ] No AI / process fix
[ ] Rule
[x] Workflow
[ ] Agent
[ ] Chưa biết
```
